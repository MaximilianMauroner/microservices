# Money spending audit

The full row-level audit from the authorized database export is stored privately at `.scratch/money-audit/spending-audit.md`. The review covers all 45 completed uncategorized spending rows. Each row has an ID, suggested category, rationale, and confidence. No category rule is recommended for automatic application from the current evidence.

The private [recommendations index](../../.scratch/money-audit/recommendations.md) and [complete ledger](../../.scratch/money-audit/ledger.md) contain financial details. They are ignored by Git and should stay local. No database record was changed during the audit.
