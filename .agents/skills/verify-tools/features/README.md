# Tools feature map

Start owned native fixtures with [verify-tools](../SKILL.md). Do not use Docker.
Record every selected entry point and result. Unselected features stay unrun.
OAuth and Convex need their own local prerequisites. Do not bypass them.

- [Publisher](publisher.md) covers native and browser upload, HTML replacement, PDF viewing and download, guest links, library, and lifecycle.
- [Authentication](authentication.md) covers sign-in, sign-out, and denied access.
- [Dashboard](dashboard.md) covers navigation and attention.
- [Status](status.md) covers service state and heartbeat prerequisites.
- [Document Share](document-share.md) covers source, collaboration, checkpoints, and export.
- [Feedback](feedback.md) covers forms, responses, languages, and sharing.
- [Money](money.md) covers import, transactions, review, and totals.
- [Settings](settings.md) covers theme and responsive navigation.
- [Operations](operations.md) covers readiness and shutdown.
