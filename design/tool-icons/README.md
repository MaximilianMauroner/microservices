# Tools Platform catalog icons

Final icons for the four public catalog entries:

- `artifact-publisher-page-style.png` — document passing through a publishing aperture.
- `field-guide-console-page-style.png` — open guide with an approval check.
- `tools-status-directory-page-style.png` — bounded catalog grid with a healthy-state indicator.
- `network-console-page-style.png` — two reachable port endpoints joined by an active connection.

The recommended page-style icons use only ink `#18211c`, accent `#087451`, and paper `#f3f1e9`, with the warm-paper canvas and restrained visual weight of the live Tools page.
Browser-ready 16, 32, and 48 pixel PNGs and 32 pixel ICO files are in `exports-page-style/`. The earlier dark-canvas set remains in `exports/` for comparison.

`field-guide-console.png` is the preserved light-canvas first pass.

`page-style-review.html` and `page-style-review.png` show the final set inside a page-faithful header, cards, and favicon-size row.
